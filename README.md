# 🧠 NeuroStudy AI: Smart Academic Operating System

**NeuroStudy AI** is a Python-based productivity and academic performance tool designed to help students optimize their daily study schedules and track long-term academic growth using algorithmic prioritization.

## 🚀 Key Features

1. **🎯 Algorithmic Priority Planner:**
   - Dynamically allocates study time based on subject difficulty and upcoming exam deadlines using a weighted priority score.
   - Automatically generates and exports an actionable daily study plan (`today_study_plan.txt`).

2. **📊 Academic Grade & Performance Analyzer:**
   - Calculates overall grade averages (`Nota Media`) on a 10-point scale.
   - Identifies the lowest-scoring subject and sets it as the primary focus target for the following week.

3. **📜 Persistent Progress Tracking:**
   - Logs weekly performance data into a permanent history file (`weekly_progress_log.txt`) to monitor improvement over time.

## 🛠️ Built With
- **Language:** Python 3
- **Core Concepts:** Data Structures, File Handling (`I/O`), Algorithmic Sorting, and Modular Programming.

## 💻 How to Run
1. Clone or download the `neuro_study.py` file.
2. Run the script in your terminal or IDE (such as VS Code):
   ```bash
   python neuro_study.py
   ```
3. Choose Mode `1`, `2`, or `3` from the interactive menu.
